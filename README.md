# Texnomart: бот оценки кандидатов (продавец-консультант)

Telegram-бот. Кандидат проходит анкету из 32 вопросов по компетенциям (оценку он не видит). Рекрутер получает карточку с процентом соответствия, вердиктом (🟢 QABUL, 🟡 ZAXIRA, 🔴 RAD) и флагами рисков, может открыть полный профиль и отметить статус. Каждый кандидат автоматически попадает в Google Таблицу.

## Файлы
| Файл | Назначение |
|---|---|
| `bot.py` | сам бот |
| `scoring.py` | вопросы, оценка, флаги (условия вакансии в блоке `JOB`) |
| `store.py` | база кандидатов (SQLite) |
| `sheets.py` | отправка в Google Таблицу |
| `apps_script.gs` | код для Google Таблицы (вставляется в Apps Script) |
| `Procfile`, `requirements.txt` | запуск на хостинге |

## Переменные окружения
| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `RECRUITER_IDS` | Telegram ID рекрутеров через запятую, узнать у @userinfobot (обязательно) |
| `SHEETS_URL` | адрес веб-приложения Apps Script, заканчивается на `/exec` (необязательно) |
| `SHEETS_SECRET` | секретное слово, такое же, как `SECRET` в `apps_script.gs` |
| `DB_PATH`, `STATE_PATH` | где хранить базу и незавершённые анкеты (если подключён постоянный диск) |

**Токен и секрет в код и в репозиторий не кладите.** Они задаются только в настройках хостинга.

## 1. Google Таблица
1. Создайте таблицу, откройте Расширения → Apps Script.
2. Вставьте содержимое `apps_script.gs`, замените `SECRET` на своё слово.
3. Deploy → New deployment → тип Web app → Execute as: Me → Who has access: Anyone → Deploy. Разрешите доступ.
4. Скопируйте адрес `.../exec` в `SHEETS_URL`, секретное слово в `SHEETS_SECRET`.
5. Лист «Nomzodlar» создастся сам при первой анкете. Ключ строки: Telegram ID, поэтому повторная анкета и смена статуса обновляют строку, а не добавляют новую.

## 2. GitHub и запуск
1. Загрузите файлы в **новый приватный** репозиторий (не поверх вашего старого бота, пока не проверите).
2. Подключите репозиторий к хостингу (Railway, Render и т.п.), тип сервиса: worker (процесс без сайта). Команда запуска: `python bot.py` (в `Procfile` уже есть). Команда установки: `pip install -r requirements.txt`.
3. Задайте переменные из таблицы выше.
4. Рекрутеру нужно один раз открыть бота и нажать Start, иначе карточки не придут.
5. Запускайте **только одну копию** бота на один токен. Если ваш старый бот работает на том же токене, остановите его или создайте нового бота у @BotFather.

## Важно
- **Диск на хостинге обычно временный.** `candidates.db` может обнулиться при перезапуске или обновлении, и тогда `/reyting` начнёт с пустой базы. Все кандидаты при этом остаются в Google Таблице. Чтобы база сохранялась, подключите постоянный диск (Volume) и укажите путь в `DB_PATH`. Условия хостингов проверяйте на их сайтах.
- В базе и таблице лежат телефоны и ответы кандидатов. Не делайте репозиторий и таблицу публичными.
- Команды рекрутера: `/reyting`, `/songgi`, `/stat`, `/csv`, `/nomzod 12`, `/n_12`, `/holat 12 chaqirildi`, `/anketa` (пройти анкету самому).
